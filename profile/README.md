# CellGuider

**Deploy and run containers on your Linux servers — on-premises or in the public cloud — from one Windows PC.**

CellGuider is Windows desktop software made by Why NotX Co., Ltd. (Republic of Korea).
Connect over SSH to the Linux servers you already run — in your office, lab or any public cloud —
then deploy, monitor and manage Docker and Podman containers from one screen.

## Editions

- **CellGuider Link**: for internet-connected servers. Personal is free (up to 3 servers);
  Plus, Team and Business are yearly software licenses.
- **CellGuider for air-gapped networks**: for sites with no internet access, sold by contract.

We sell software only. We do not provide servers, hosting or VPN — you bring your own servers or cloud instances.
